## 🔒 隐私政策要点

### 数据收集
- **用户数据**：仅存储必要的认证令牌和用户偏好设置
- **操作数据**：记录发布任务状态（不包含内容详情）
- **不收集**：用户浏览历史、个人身份信息

### 数据使用
- 认证令牌用于 API 访问
- 用户偏好用于个性化体验
- 操作数据用于故障排查和功能优化

### 数据存储
- 本地存储（Chrome storage API）
- 端到端加密传输
- 无第三方数据共享

## 🚀 提交步骤

1. **打包扩展**
   ```bash
   npm run build
   ```

2. **验证扩展**
   - 在 Chrome 中加载已解压的扩展
   - 测试所有功能
   - 检查控制台无错误

3. **生成 ZIP 包**
   - 压缩 `.output/chrome-mv3/` 目录
   - 确保 ZIP 文件 < 15 MB

4. **提交到 Chrome 商店**
   - 访问：https://chrome.google.com/webstore/devconsole
   - 上传 ZIP 包
   - 填写所有必填信息
   - 提交审核
