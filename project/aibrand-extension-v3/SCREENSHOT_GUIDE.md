## 🎨 设计规范

### 视觉风格
1. **背景**：使用干净的浏览器窗口截图
2. **主题色**：蓝紫色渐变（#3B82F6 → #8B5CF6）
3. **字体**：清晰易读的系统字体
4. **语言**：简体中文

### 内容要求
- 所有文字清晰可读
- 界面元素完整可见
- 无遮挡或截断
- 显示扩展 logo 和品牌标识

### 技术要点
1. 使用 Chrome 浏览器（浅色主题）
2. 隐藏浏览器地址栏中的敏感信息
3. 使用模拟数据，不显示真实用户数据
4. 确保所有按钮和图标清晰可见

## 📝 截图脚本示例

### 截图 1 脚本
1. 打开 Chrome 浏览器
2. 访问 AiBrand Web 应用
3. 登录测试账户
4. 打开侧边面板
5. 创建一篇测试内容
6. 选择 2-3 个平台
7. 截取浏览器窗口

### 截图 2 脚本
1. 在侧边面板中点击"AI 助手"
2. 输入提示词："写一条关于人工智能的有趣微博"
3. 点击"生成"按钮
4. 等待 AI 生成完成
5. 展示生成结果和置信度
6. 截取浏览器窗口

### 截图 3 脚本
1. 打开一个社交媒体帖子页面（如微博）
2. 在侧边面板中点击"互动"标签
3. 依次展示点赞、收藏、关注按钮
4. 点击其中一个按钮
5. 展示操作成功反馈
6. 截取浏览器窗口

### 截图 4 脚本
1. 在侧边面板中点击"评论"标签
2. 输入评论内容
3. 选择目标平台和帖子
4. 点击"发布评论"按钮
5. 展示发布成功状态
6. 截取浏览器窗口
