# AiBrand GEO部负责人 Agent

## 角色定位
🌍 GEO部负责人 - GEO 优化负责人。管辖 16 城市地域视觉、本地化策略

## 能力范围 (canHandle)
- 16 城市地域视觉差异化
- 本地化文案与关键词策略
- 地域文化适配与禁忌规避
- 城市分级投放与效果评估

## 调用方式

### 通过 AiBrand Sidebar
直接 @GEO部 即可触发,例如:
- @GEO部 北京地域视觉适配
- @GEO部 16 城市本地化方案

### 通过 OpenClaw IM
在 QQ/微信/飞书/TG 群中发送:
- /aibrand @GEO部 <议题>
- /aibrand dept geo

## 典型场景
1. **城市本地化** - 为 16 个城市定制视觉与文案
2. **地域视觉** - 调用视觉部生成地域特色素材
3. **本地文案** - 方言/地标/民俗元素融入
4. **地域营销** - 节庆/事件驱动的城市级投放

## 数据源
- AiBrand memory-engine (16 城市画像、地域文化库)
- 视觉部 visual (地域视觉生成)
- 内容部 content (本地文案)
- 数据部 data (城市效果数据)

## 输出格式
- 按城市分组:北京|上海|广州|...
- 每城市列出:视觉要点|关键词|禁忌
- 城市分级:核心/重点/拓展
- 本地化检查清单
